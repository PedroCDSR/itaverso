# ITAMANIA, o mundo de Itajubá

Jogo de plataforma 2D para celular sobre Itajubá/MG, com a linguagem de um jogo de 16 bits. Geraldo ou Helena chega
de ônibus à cidade, sonha em pilotar helicóptero, estuda na UNIFEI e termina cuidando de Itajubá. Cada fase é um
lugar real e termina com uma curiosidade sobre a cidade.

- Regras de trabalho: [CLAUDE.md](CLAUDE.md)
- História e fases: [itamania/DESIGN.md](itamania/DESIGN.md)
- Andamento: [itamania/STATUS.md](itamania/STATUS.md)

## Rodar no computador

Precisa do Node 22.

```bash
cd itamania
```

```bash
npm install
```

```bash
npm run dev
```
